# Personal Expense Tracker💸 (Build with AI)

**Spend** is a lightweight, browser-based expense tracker. Record everyday spending in Bangladeshi taka (BDT), review monthly totals, and keep an eye on a budget—all from a single page.

## Features

- Add expenses with a description, amount, category, and date. You can also add an expense without an amount and fill it in later.
- View monthly totals and browse expenses by month.
- Search expenses and filter by category.
- Set a monthly budget and see how much you have spent, how much remains, or how far you are over.
- Schedule weekly or monthly recurring expenses. Due entries are added when the app is open, with an in-app reminder and an optional system notification. Allow notifications in your browser to enable system alerts; the app must remain open. Notifications while it is closed require a push-notification backend.
- Export the selected month and current filters as a CSV file.
- Switch between light and dark themes.
- Optionally estimate totals in another currency using the daily rate from [Frankfurter](https://frankfurter.dev/).

## Getting started

There is no build step or dependency installation. Open `index.html` in a modern web browser to use the app.

## Data and privacy

Expenses, budgets, recurring schedules, and preferences are saved in your browser's local storage. They are not synced to a server, so they are available in the same browser profile where you entered them. Clearing that browser's site data may remove them.

Currency conversion requires an internet connection. Exchange rates are indicative estimates and may differ from rates used by a bank or card provider.
